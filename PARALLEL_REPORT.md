Все тесты "моргали", потому что все действия проводились на одном аккаунте, и действия одного воркера влияли на состояние
системы второго воркера.
Исправил путем создания уникального аккаунта, для каждого теста отдельно
reset-db недопустим, потому что влияет на всю систему в общем, даже если воркеры взаимодействуют с разными аккаунтами,
сброс базы данных очистит состояние всех аккаунтов, то есть, например, первый воркер закончил быстрее всех работу и 
вызвал reset-db, то это повлияет на всех воркеров, не учитывая разные аккаунты


Чтобы создать заказ через UI, необходимо выполнить следующие шаги:
1) Открыть страницу Логин
2) Авторизироваться
3) Перейти на страницу Каталог
4) Добавить товар в корзину
5) Принять alert
6) Перейти на страницу Корзина
7) Оформить заказ
8) В alert ввести Имя получателя
9) В alert ввести Номер телефона
10) В alert ввести Адрес
11) Принять alert, что заказ оформлен

Чтобы создать заказ через API, необходимо выполнить следующие шаги:
1) Запрос на добавление товара в корзину
2) Запрос на оформление заказа

Через api всегда стоит подготавливать всё состояние системы для итоговой проверки через UI,
