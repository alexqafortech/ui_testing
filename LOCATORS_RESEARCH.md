# Разведка локаторов: пять сайтов

## 1. Wildberries (https://www.wildberries.ru/)

| Элемент | Локатор | Почему такой |
| Поле поиска в шапке | `searchBlock'` | Есть id, который указывает на конкретное поле|
| Кнопка "Адрес доставки"|`[data-testid = 'geo-delivery-points-popup-open-button']`| Есть специальный testid|
| Блок со звездами рейтинга приложения | `#smartBanner .smart-banner__stars`| Конкретное указание на блок, и в последующем указание баннера, который нам нужен|
| Кнопка "Новостройки" | `//li/a[contains(text(), 'Новостройки''` | Поиск по тексту, который вряд ли будет меняться |
| Кнопка открытия чата поддержки | `[aria-label = 'Чат']` | Есть специально прописанный aria-label |

## 2. GitHub (https://github.com/)

| Элемент | Локатор | Почему такой |
| Кнопка открытия бокового меню | `[data-testid = 'top-nav-left'] button[data-component*='IconButton']`| Есть testid у родителя, и название компонента|
| Аватар профиля | `[data-testid = 'github-avatar']`| Есть прописанный testid|
| Кнопка создания нового репозитория| `div[data-target^='loading-context.details'] a[href^='/new']`| У кнопки нет прописанного id, так же на эту ссылку ведёт две кнопки, для уточнения добавлен div в котором содержится необходимая кнопка|
| Поле ввода текста в чат | `[id='copilot-chat-textarea']` | Есть прописанный id элемента |
| Кнопка Dashboard | `//span[contains(text(), 'Dashboard')]` | Текст вряд ли будет меняться |

## 3. Кинопоиск (https://www.kinopoisk.ru/)
| Элемент | Локатор | Почему такой |
| Логотип | `[alt = 'Кинопоиск']`| Единственный обладает таким alt|
| Кнопка "Закладки| `[aria-label = 'Буду смотреть']`| Прописан aria-label|
| Поле поиска | `//input[@name='text' and @placeholder='Фильмы, сериалы, персоны']']`| Страница содержит всего один импут, в случае сли добавят новые, есть уточнение placeholder, который вряд ли будут менять|
| Ссылка для редиректа на страницу покупки билетов| `//a[contains(text(), 'Билеты в кино')]`| Текст ссылки скорее всего не будет меняться|
| Кнопка для открытия бокового меню| `[aria-label="Меню"]`| Прописан уникальный aria-label|

## 4. Яндекс.Музыка (https://music.yandex.ru/)
| Элемент | Локатор | Почему такой |
| Кнопка "Воспроизведение" | `section[aria-label = 'Плеер'] [aria-label='Воспроизведение']`| На странице 27 элементов в aria-label='Воспроизведение' для изоляции уточнение section|
| Кнопка перехода на главную страницу| `div[class*='NavbarDesktop_root'] use[xlink\\:href='/icons/sprite.svg#musicLogo']`| Нет idшников, или других атрибутов, за которые можно зацепиться|
| Кнопка "Скачать десктопное приложение"| `[aria-label='Скачать приложение']`| Есть aria-label, который вряд ли будет меняться|
| Название "Моя волна"| `//div[@class='VibePage_entityMeta__dhDch']//span[contains(text(), 'Моя волна')]`| Существует 2 span с таким текстом, для уточнения, добавлен div, который находится выше на уровень|
| Кнопка для открытия Профиля| `button[aria-label='Ваш профиль']`| Есть прописанный aria-label|

## 5. Ozon (https://www.ozon.ru/)
| Элемент | Локатор | Почему такой |
| Кнопка для открытия "Каталог" | `div[data-widget='catalogMenu'] button[class='b25_9_1-a b25_9_1-b7 b25_9_1-b4']`| Кнопки имеет странный class, ничего больше не имеет, в связи с этим дополнительно указал в каком div находится кнопка|
| Кнопка для открытия "Корзины"| `a[href='/cart']`| Имеется всего один элемент "a", у которого ссылка на Корзину|
| Кнопка для открытия "Билеты, отели" | `//a[contains(text(), 'Билеты, отели')]`| Текст ссылки вряд ли будет меняться|
| Поле ввода текста для поиска товара| `form[action='/search'] input`| В блок поиска товара вряд ли будет добавляться ещё одно поле ввода текста|
| Отображение цены на первой карточке товара| `$x("(//div[@data-index='0']//*[contains(text(), '₽')])[1]")`| Сложная структура, поэтому понадобилось искать по массиву, через селекторы не получится, по причине, того что в одной карточке может несколько раз дублироваться|
